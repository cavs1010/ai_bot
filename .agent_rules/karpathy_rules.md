# Karpathy Engineering Principles

## Core Guidelines
1. **Think Before Coding**:
   - Surface assumptions explicitly.
   - State trade-offs clearly.
   - Never assume functionality without verifying existing code and evidence.

2. **Simplicity First**:
   - Write the minimum surgical code required to solve the problem directly.
   - Avoid speculative abstractions, unnecessary layers, or defensive over-engineering.

3. **Surgical Changes**:
   - Touch only what is strictly necessary to implement the feature or fix.
   - Match existing codebase style and structural conventions.
   - Do not perform broad refactoring alongside surgical bug fixes.

4. **Goal-Driven Execution**:
   - Define clear, falsifiable success criteria before making changes.
   - Make fast, direct modifications and verify them immediately.
