# Agent Rules — Spec

The live spec is [`spec_development/NOW.md`](../spec_development/NOW.md). That file is the only source of truth for the active milestone and the feature to work on.

Before planning or coding, read `spec_development/NOW.md` and stay on the active feature.

- New ideas go in [`spec_development/Milestone Backlog.md`](../spec_development/Milestone%20Backlog.md) under `## 💡 Candidates`.
- Finished milestones stay in `spec_development/Completed Milestones/`.
- Do not create or read `spec/master.md`, iteration roadmaps, or ideas files under `spec/`. That tree is not the live spec.
- When editing `spec_development/`, follow `AGENTS.md`: do not mark work completed without human approval, and do not fill `NOW.md` ahead of the user.

Also follow [`function_definition_rules.md`](./function_definition_rules.md) when writing code.
