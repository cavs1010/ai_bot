# **1. Pre-Market Gap Scanner**

|  |
| --- |
| **PRIORITY 1 — MUST EXIST BEFORE PAPER TRADING** |

|  |
| --- |
| Our stop losses are set at 2%. But stop losses do not protect against overnight gaps. If a stock drops 15% before the market opens — because of news that broke at midnight — our stop loss triggers at the open price, which is already down 15%.  This scanner runs at 8am AEST every morning, before the US market opens. It reads overnight news for every open position and closes anything with a critical negative score before the opening bell.  **Plain English: The bot checks every open position for overnight bad news before the market opens. If it finds something serious — it sells at open before the damage compounds.** |

| **SCENARIO** | **WITHOUT SCANNER** | **WITH SCANNER** |
| --- | --- | --- |
| Company announces fraud at midnight | Stop at -2% but fills at -18% at open | Bot reads fraud news. Scores -9/10. Queues sell at open. Exits at -4% not -18%. |
| CEO resigns unexpectedly overnight | Gap down -12%. Stop loss misses by 10% | Scanner flags leadership risk. Exits pre-market. Loss contained. |
| Positive overnight news | Normal morning — no action needed | Scanner confirms clean. Positions held. Normal day. |

### **pre\_market\_scanner.py**

import anthropic, json, schedule, time

from datetime import datetime

from alpaca\_news import get\_stock\_news

from alerts import send\_alert

client = anthropic.Anthropic()

def scan\_overnight\_news(ticker):

"""Read overnight news and score risk for open position."""

news = get\_stock\_news(ticker, hours=8)

if not news:

return 0, "No overnight news"

prompt = f"""

Analyse overnight news for {ticker}.

Score RISK from -10 to 0 only:

0 = no concerning news

-3 = mild negative (analyst downgrade, minor miss)

-6 = significant (guidance cut, major lawsuit)

-9 = critical (fraud, CEO sudden exit, regulatory shutdown)

Return ONLY JSON: {"score": X, "reason": "brief reason"}

News: {news[:5]}

"""

response = client.messages.create(

model="claude-sonnet-4-20250514", max\_tokens=150,

messages=[{"role":"user","content":prompt}]

)

result = json.loads(response.content[0].text)

return result["score"], result["reason"]

def pre\_market\_safety\_check(alpaca, active\_positions):

"""Run at 8am AEST — before US market opens."""

print("Pre-market safety check starting...")

exits = []

for symbol, pos in list(active\_positions.items()):

# Queue sell at open

symbol=symbol,

qty=pos["shares"],

# **2. Portfolio Drawdown Circuit Breaker**

|  |
| --- |
| **PRIORITY 2 — MUST EXIST BEFORE PAPER TRADING** |

|  |
| --- |
| Individual trade stop losses protect each position. But there is no protection against a sequence of losses across multiple positions across multiple weeks. Without a circuit breaker the bot keeps trading at full size through a losing streak until the account is seriously damaged.  The circuit breaker tracks the highest pot value ever reached (the peak) and monitors how far below that peak the current pot sits. When the gap gets too large the bot automatically reduces position sizes, switches to paper-only, or stops entirely.  **Plain English: Three levels of protection. Warning at -8% — trade smaller. Pause at -12% — paper trade only, no real money. Stop at -20% — full halt, human review required.** |

| **LEVEL** | **DRAWDOWN THRESHOLD** | **BOT ACTION** | **PLAIN ENGLISH** |
| --- | --- | --- | --- |
| **NORMAL** | 0% to -8% | Full operation — standard position sizes | Everything fine. Trade normally. |
| **WARNING** | -8% to -12% | Reduce all positions by 50% | Something is going wrong. Trade smaller until it stabilises. |
| **PAUSE** | -12% to -20% | Switch to paper trading only — no real money | Losing streak detected. Keep practising but stop risking real capital. |
| **STOP** | Below -20% | Full halt — human review required | Critical. Stop everything. Review what went wrong before resuming. |

### **drawdown\_protection.py**

from alerts import send\_alert

DRAWDOWN\_LEVELS = {

"warning": 0.08, # 8% — reduce size

"pause": 0.12, # 12% — paper only

"stop": 0.20, # 20% — full halt

}

peak\_pot = 10000.0 # Update this as pot grows

def update\_peak(current\_pot):

"""Track highest pot value ever reached."""

global peak\_pot

if current\_pot > peak\_pot:

peak\_pot = current\_pot

return peak\_pot

def check\_drawdown(current\_pot):

"""

Check current drawdown against peak.

Returns: (status, drawdown\_pct, position\_multiplier)

"""

peak = update\_peak(current\_pot)

drawdown = (peak - current\_pot) / peak

if drawdown >= DRAWDOWN\_LEVELS["stop"]:

send\_alert(f"CRITICAL: Drawdown {drawdown:.1%} — BOT STOPPED", "CRITICAL")

return "STOP", drawdown, 0.0

if drawdown >= DRAWDOWN\_LEVELS["pause"]:

send\_alert(f"WARNING: Drawdown {drawdown:.1%} — Switching to paper", "WARNING")

return "PAPER\_ONLY", drawdown, 0.0

if drawdown >= DRAWDOWN\_LEVELS["warning"]:

send\_alert(f"CAUTION: Drawdown {drawdown:.1%} — Reducing sizes 50%", "WARNING")

return "REDUCED", drawdown, 0.5

return "NORMAL", drawdown, 1.0

# **3. Order Error Handling**

|  |
| --- |
| **PRIORITY 3 — MUST EXIST BEFORE PAPER TRADING** |

|  |
| --- |
| Without error handling the bot will silently fail when Alpaca rejects an order. A halt on a stock, insufficient funds, a network timeout, a market closure — any of these will cause the bot to think a trade executed when it did not. Positions will be tracked that do not exist. Stops will be set on positions that were never opened.  **Plain English: Every order must be wrapped in error handling that catches the failure, logs it, and alerts you immediately rather than continuing as if the trade happened.** |

### **order\_handler.py**

from alerts import send\_alert

from logger import log\_error

import time

def safe\_submit\_order(alpaca, symbol, qty, side, retries=2):

"""

Submit order with full error handling.

Retries once on timeout. Alerts on all failures.

Returns order object or None if failed.

"""

for attempt in range(retries + 1):

try:

order = alpaca.submit\_order(

symbol=symbol, qty=qty,

side=side, type="market",

time\_in\_force="day"

)

print(f" Order OK: {side} {qty} {symbol}")

return order

except Exception as e:

err = str(e).lower()

if "halted" in err:

send\_alert(f"CRITICAL: {symbol} trading halted — cannot execute {side}", "CRITICAL")

log\_error(symbol, "HALTED", str(e))

return None # Do not retry

if "insufficient" in err or "buying power" in err:

send\_alert(f"WARNING: Insufficient funds for {symbol}", "WARNING")

log\_error(symbol, "INSUFFICIENT\_FUNDS", str(e))

return None

if "market closed" in err:

log\_error(symbol, "MARKET\_CLOSED", str(e))

return None

if attempt < retries:

print(f" Retry {attempt+1} for {symbol} in 5s...")

time.sleep(5)

continue

# Unknown error after all retries

send\_alert(f"CRITICAL: Order failed {symbol}: {str(e)[:100]}", "CRITICAL")

log\_error(symbol, "UNKNOWN", str(e))

return None

return None

def verify\_position(alpaca, symbol, expected\_qty):

"""Confirm position actually exists after order."""

try:

pos = alpaca.get\_position(symbol)

actual\_qty = int(pos.qty)

if actual\_qty != expected\_qty:

send\_alert(f"WARNING: {symbol} qty mismatch. Expected {expected\_qty} got {actual\_qty}", "WARNING")

return actual\_qty

except:

send\_alert(f"WARNING: Cannot verify position {symbol} — may not have filled", "WARNING")

return 0

# **5. Market Regime Detection**

|  |
| --- |
| **PRIORITY 5 — BUILD DURING PAPER TRADING** |

|  |
| --- |
| Momentum strategies work brilliantly in trending markets. They bleed money in choppy, sideways markets. The S&P 500 spends roughly 30-40% of its time going sideways with no clear direction. In those periods our RSI and SMA signals fire constantly but the moves immediately reverse, stopping us out for small losses repeatedly.  The regime detector reads the broader market every night before the nightly scan and adjusts the bot's behaviour accordingly — raising the threshold to only take the highest conviction trades in choppy markets, or shutting down entirely in bear markets.  **Plain English: Before picking stocks each night, the bot checks what kind of market environment it is operating in and adjusts how aggressive or defensive it needs to be.** |

| **REGIME** | **HOW BOT DETECTS IT** | **BOT BEHAVIOUR CHANGE** |
| --- | --- | --- |
| **Trending up** | SPY above SMA20 and SMA50. 60%+ up days in last 20. VIX below 18. | Full operation. Standard thresholds. All sectors eligible. |
| **Neutral** | SPY between SMA20 and SMA50. Mixed up/down days. VIX 18-22. | Normal operation. Slightly tighten composite threshold to 68. |
| **Choppy/sideways** | SPY flat. ATR low. Less than 50% up days. Many reversals. | Raise threshold to 75. Reduce position sizes 30%. Only Tier A signals. |
| **Trending down** | SPY below SMA20 and SMA50. 40% or fewer up days. VIX rising. | Defensive mode. Reduce sizes 60%. No new Gear 2 trades. Cash preferred. |
| **High volatility** | VIX above 25. Large daily swings. ATR elevated across all stocks. | Reduce all sizes 50%. Tighten stops. Prioritise defensive sectors. |

### **market\_regime.py**

import yfinance as yf

import numpy as np

def detect\_market\_regime():

"""

Detect current market environment.

Returns: (regime, vix, position\_multiplier, threshold\_adjustment)

"""

spy = yf.Ticker("SPY").history(period="60d")

vix = yf.Ticker("^VIX").fast\_info["last\_price"]

close = spy["Close"]

sma20 = close.rolling(20).mean().iloc[-1]

sma50 = close.rolling(50).mean().iloc[-1]

current = close.iloc[-1]

daily\_ret = close.pct\_change().dropna()

up\_days = (daily\_ret > 0).sum() / len(daily\_ret)

avg\_move = daily\_ret.abs().mean() \* 100

# High volatility — check first

if vix > 25:

return "HIGH\_VOL", vix, 0.5, +10 # Raise threshold

# Trending down

if current < sma20 < sma50 and up\_days < 0.42:

return "TRENDING\_DOWN", vix, 0.4, +10

# Choppy sideways

if avg\_move < 0.4 and abs(current - sma20) / sma20 < 0.01:

return "CHOPPY", vix, 0.7, +10

# Neutral

if current > sma20 and up\_days >= 0.50:

return "NEUTRAL", vix, 0.85, +3

# Trending up

if current > sma20 > sma50 and up\_days > 0.58:

return "TRENDING\_UP", vix, 1.0, 0

return "NEUTRAL", vix, 0.85, +3

# **6. Volatility-Adjusted Position Sizing**

|  |
| --- |
| **PRIORITY 6 — BUILD DURING PAPER TRADING** |

|  |
| --- |
| Equal dollar weighting across 3 positions sounds fair but creates unequal real risk. A stock with a 6% ATR creates 3x more daily dollar volatility in your pot than a stock with a 2% ATR — even in the same dollar position. This means some positions create far more emotional pressure and actual loss risk than others.  **Plain English: Size every position so that a 2% stop loss always costs exactly the same dollar amount — regardless of how volatile the stock is. This means smaller positions in wilder stocks.** |

### **position\_sizer.py**

def calculate\_position\_size(pot, entry\_price, atr\_pct,

max\_risk\_pct=0.02, max\_position\_pct=0.34):

"""

Size position so a 2% stop always risks exactly 2% of pot.

No single position exceeds one-third of pot.

Example:

Pot: $10,000. Max risk per trade: $200 (2%).

Stock A: ATR 2%. Stop distance = $20 on $1000 stock.

Shares = $200 / $20 = 10 shares = $10,000 position (capped to $3,400)

Stock B: ATR 6%. Stop distance = $60 on $1000 stock.

Shares = $200 / $60 = 3 shares = $3,000 position (no cap needed)

"""

dollar\_risk = pot \* max\_risk\_pct # Always $200 on $10k

stop\_distance = entry\_price \* (atr\_pct/100) # Dollar distance to stop

shares = int(dollar\_risk / stop\_distance)

position\_value = shares \* entry\_price

max\_position = pot \* max\_position\_pct # Never exceed 1/3 of pot

if position\_value > max\_position:

shares = int(max\_position / entry\_price)

position\_value = shares \* entry\_price

return shares, round(position\_value, 2)

# **7. Tax Tracking**

|  |
| --- |
| **PRIORITY 7 — BUILD DURING PAPER TRADING** |

|  |
| --- |
| Every trade is a Capital Gains Tax event in Australia. With the bot executing 3-5 trades per week the ATO will classify you as a trader — meaning profits are taxed at your marginal income tax rate, not the 50% CGT discount. At the 37% bracket on $30,000 profit that is $11,100 in tax.  Beyond the rate, the ATO requires precise records: entry date, entry price, exit date, exit price, brokerage costs, and the AUD equivalent of every USD transaction at the time of the trade. Without automated tracking from day one this becomes an overwhelming compliance problem.  **Warning: Do not start live trading without speaking to an Australian accountant about whether to trade personally or through a company structure. The difference in tax treatment can be significant.** |

| **ATO REQUIREMENT** | **WHAT THE BOT MUST RECORD** | **WHY** |
| --- | --- | --- |
| Entry date and price | Exact timestamp and USD price of every buy | CGT cost base calculation |
| Exit date and price | Exact timestamp and USD price of every sell | Realised gain or loss calculation |
| AUD equivalent at trade time | USD/AUD rate at moment of each trade | ATO requires AUD values not USD |
| Brokerage costs | Any commissions or fees paid | Deductible against gains |
| Trade classification | Gear 1 vs Gear 2, sector, signals that triggered | Supports trader vs investor classification if disputed |

def calculate\_tax\_liability(trades, marginal\_rate=0.37):

"""Estimate current year tax liability on closed trades."""

buys = {t["symbol"]: t for t in trades if t["action"] == "BUY"}

sells = [t for t in trades if t["action"] == "SELL"]

total\_gain = 0

for sell in sells:

sym = sell["symbol"]

if sym in buys:

cost = buys[sym]["total\_aud"]

proceeds = sell["total\_aud"]

total\_gain += (proceeds - cost)

tax\_estimate = max(0, total\_gain \* marginal\_rate)

return round(total\_gain, 2), round(tax\_estimate, 2)

def generate\_weekly\_report(pot\_start, pot\_end):

"""Generate and email weekly performance summary."""

trades = []

if Path(TRADE\_LOG).exists():

with open(TRADE\_LOG) as f: trades = json.load(f)

closed = [t for t in trades if t["status"] == "CLOSED"]

wins = [t for t in closed if (t["pnl"] or 0) > 0]

losses = [t for t in closed if (t["pnl"] or 0) <= 0]

total\_wins = sum(t["pnl"] for t in wins)

total\_losses = abs(sum(t["pnl"] for t in losses))

profit\_factor = round(total\_wins / total\_losses, 2) if total\_losses > 0 else 999

win\_rate = round(len(wins) / len(closed) \* 100, 1) if closed else 0

weekly\_return = round((pot\_end - pot\_start) / pot\_start \* 100, 2)

report = f"""

WEEKLY PERFORMANCE REPORT

Week ending: {datetime.now().strftime("%Y-%m-%d")}

POT: ${pot\_start:,.2f} -> ${pot\_end:,.2f} ({weekly\_return:+.2f}%)

TRADES: {len(closed)} closed | {len(wins)} wins | {len(losses)} losses

WIN RATE: {win\_rate}%

PROFIT FACTOR: {profit\_factor} (target: above 2.0)

AVG WINNER: {round(sum(t["pnl\_pct"] for t in wins)/len(wins),2) if wins else 0}%

AVG LOSER: {round(sum(t["pnl\_pct"] for t in losses)/len(losses),2) if losses else 0}%

"""

send\_alert(report, level="INFO")

return {

"win\_rate": win\_rate, "profit\_factor": profit\_factor,

"weekly\_return": weekly\_return, "total\_trades": len(closed)

}

# **9. Backtesting Framework**

|  |
| --- |
| **PRIORITY 9 — BEFORE GOING LIVE WITH REAL MONEY** |

|  |
| --- |
| Backtesting runs the bot's selection logic against historical price data to see what would have happened. It does not use historical news data — that requires paid providers. Instead it tests whether the momentum signals alone (RSI, SMA, volume, ATR) would have identified good trades historically.  The honest caveat: backtesting momentum signals without historical sentiment data will overestimate performance because sentiment is 30% of the composite score. Treat backtest results as a floor — live performance with sentiment should be equal or better.  **Target: backtest should show positive returns across at least 2 different market conditions (trending up and choppy) before going live.** |

### **backtest.py**

import yfinance as yf

import pandas as pd

from datetime import datetime, timedelta

def backtest\_momentum\_signals(tickers, start\_date, end\_date,

initial\_capital=10000,

composite\_threshold=65,

stop\_pct=0.02,

trail\_pct=0.015):

"""

Backtest momentum signal selection on historical data.

Uses price-based signals only (no historical news).

"""

results = []

pot = initial\_capital

pot\_history = [pot]

# Download historical data

data = {}

for ticker in tickers:

df = yf.download(ticker, start=start\_date, end=end\_date, progress=False)

if not df.empty:

df["SMA20"] = df["Close"].rolling(20).mean()

df["SMA50"] = df["Close"].rolling(50).mean()

df["RSI"] = calculate\_rsi(df["Close"])

df["ATR"] = calculate\_atr(df)

df["VolRatio"] = df["Volume"] / df["Volume"].rolling(20).mean()

data[ticker] = df

# Walk forward day by day

dates = pd.bdate\_range(start\_date, end\_date)

for i, date in enumerate(dates[50:], 50):

candidates = []

for ticker, df in data.items():

if date not in df.index: continue

row = df.loc[date]

if pd.isna(row["RSI"]): continue

# Apply momentum score (no sentiment in backtest)

score = 0

rsi = row["RSI"]

if 60 <= rsi <= 70: score += 30

elif 70 < rsi <= 75: score += 20

if row["Close"] > row["SMA20"]: score += 25

if row["SMA20"] > row["SMA50"]: score += 25

vol = row["VolRatio"]

if vol >= 2.0: score += 35

elif vol >= 1.5: score += 30

elif vol >= 1.2: score += 20

normalised = min(round(score / 1.1, 0), 100)

if normalised >= composite\_threshold:

candidates.append({"ticker": ticker, "score": normalised,

"price": row["Close"], "date": date})

# Select top 3

top3 = sorted(candidates, key=lambda x: x["score"], reverse=True)[:3]

# Simulate trades — hold 3-5 days with trail stop

for stock in top3:

entry = stock["price"]

pos = pot / 3

highest = entry

hold\_days = min(5, len(dates) - i - 1)

for j in range(1, hold\_days + 1):

if i+j >= len(dates): break

next\_date = dates[i+j]

if next\_date not in data[stock["ticker"]].index: break

price = data[stock["ticker"]].loc[next\_date]["Close"]

highest = max(highest, price)

gain = (price - entry) / entry

# Hard stop

if gain <= -stop\_pct:

pnl = pos \* gain

results.append({\*\*stock, "exit": price, "pnl": pnl,

"exit\_type": "STOP", "hold": j})

pot += pnl

break

# Trail stop (after 3% gain)

if gain >= 0.03:

trail = highest \* (1 - trail\_pct)

if price <= trail:

pnl = pos \* ((price - entry) / entry)

results.append({\*\*stock, "exit": price, "pnl": pnl,

"exit\_type": "TRAIL", "hold": j})

pot += pnl

break

pot\_history.append(pot)

wins = [r for r in results if r["pnl"] > 0]

losses = [r for r in results if r["pnl"] <= 0]

win\_rate = len(wins) / len(results) \* 100 if results else 0

pf = sum(r["pnl"] for r in wins) / abs(sum(r["pnl"] for r in losses)) if losses else 999

return {

"final\_pot": round(pot, 2),

"total\_return": round((pot - initial\_capital) / initial\_capital \* 100, 2),

"total\_trades": len(results),

"win\_rate": round(win\_rate, 1),

"profit\_factor": round(pf, 2),

"pot\_history": pot\_history,

"trades": results

}

def calculate\_rsi(prices, period=14):

delta = prices.diff()

gain = delta.clip(lower=0).rolling(period).mean()

loss = (-delta.clip(upper=0)).rolling(period).mean()

rs = gain / loss

return 100 - (100 / (1 + rs))

def calculate\_atr(df, period=14):

hl = df["High"] - df["Low"]

hpc = abs(df["High"] - df["Close"].shift())

lpc = abs(df["Low"] - df["Close"].shift())

tr = pd.concat([hl,hpc,lpc], axis=1).max(axis=1)

return tr.rolling(period).mean()
