# **1. Why One Big Claude Question Fails**

|  |
| --- |
| **IN PLAIN ENGLISH**  Imagine handing someone 15 news articles, a chart, the VIX reading, sector data, and an earnings calendar all at once and asking for one thumbs up or thumbs down. Even the smartest person would struggle — they might let a strong positive headline cancel out a serious warning buried in article 11.  Claude has the same problem. The solution is to never ask Claude one big question. We ask five small, focused questions in order. Each has a binary or structured answer. No hedging allowed. |

|  |  |  |
| --- | --- | --- |
| **FAILURE MODE** | **WHAT HAPPENS** | **CONSEQUENCE** |
| **Signal Averaging** | Positive news + negative macro = Claude calls it neutral | Bot enters a trade it should have skipped |
| **Recency Bias** | Whatever appears last in the prompt gets weighted most | Decision changes based on order of information |
| **Contradiction Paralysis** | Bullish signal + bearish macro = Claude hedges | Bot enters when correct answer was SKIP |

|  |
| --- |
| **THE RULE**  Claude is never asked to weigh contradictory information simultaneously. Each gate asks one focused question with a structured answer format that forces a clear decision. Hedging is not an acceptable answer. |

# **2. The 5-Gate Sequential System — Overview**

|  |
| --- |
| **IN PLAIN ENGLISH**  Think of this as airport security. You do not reach the departure gate without passing every checkpoint in order. The moment you fail one, you are turned around. You never reach the next checkpoint.  Gate 1 uses hardcoded rules only — no Claude, no API cost, runs in milliseconds. Gates 2, 3, and 4 each ask Claude one specific focused question. Gate 5 is the final signal — Claude only reaches this if the trade has cleared every previous check. |

|  |  |  |  |
| --- | --- | --- | --- |
| **GATE** | **NAME** | **QUESTION ASKED** | **REJECT IF** |
| **1** | **Hard Threat Screen** | Are any known hard blockers present? | Any single blocker is present |
| **2** | **News Threat Assessment** | Is there serious risk hidden in the news? | Claude answers YES |
| **3** | **Sentiment Quality Check** | Is the news picture bullish, bearish, or neutral? | Bearish OR neutral with confidence below 6 |
| **4** | **Contradiction Detection** | Does market context contradict the bullish signal? | YES + HIGH risk = block. YES + MEDIUM = human review |
| **5** | **Final Signal + EV** | Generate final BUY signal and EV calculation | EV below 4% threshold |

## **3.4 Source Quality Weighting — How Claude Scores Each Source**

|  |
| --- |
| **IN PLAIN ENGLISH**  Not all news sources are equal. A Reuters headline about a SEC investigation is far more significant than a StockTwits post saying the same thing. Claude needs to know which sources to trust more and weight accordingly in Gate 3.  This weighting is built into the Gate 3 prompt — Claude is told explicitly which sources are HIGH, MEDIUM, and LOW reliability and must factor that into its confidence score. A bullish headline from a LOW reliability source gets a lower confidence score than the same sentiment from a HIGH reliability source.  This prevents the bot from acting on retail hype dressed up as news. |

|  |  |  |  |
| --- | --- | --- | --- |
| **RELIABILITY** | **SOURCES IN THIS TIER** | **CONFIDENCE IMPACT** | **PLAIN ENGLISH** |
| **HIGH** | Reuters, Bloomberg, WSJ, Financial Times, AP, Alpaca/Benzinga breaking news | Full weight — confidence score taken at face value | Major professional news outlets. If Reuters says it, it is probably true. |
| **MEDIUM** | CNBC, MarketWatch, Seeking Alpha, Motley Fool, Finnhub company news | Reduced weight — confidence score discounted 20% | Reputable but sometimes sensational or opinion-based. Valid signal but verify. |
| **LOW** | Press releases, company IR blogs, StockTwits, Reddit, unknown blogs | Minimal weight — confidence score discounted 50% | Could be accurate but treat with significant scepticism. Never trade on LOW alone. |
| **DANGEROUS** | Unverified social media, anonymous posts, penny stock forums | Gate 2 threat flag — is this a pump attempt? | Active disinformation risk. Claude should flag these as potential manipulation. |

# **5. Exogenous Shock Memory System**

|  |
| --- |
| **IN PLAIN ENGLISH**  This is how the bot learns from events it could not have predicted — and why it gets smarter over time rather than repeating the same expensive mistakes.  When something completely outside our signals causes a loss, we log it, categorise it, and add it to a growing threat memory database. Over 6 months of paper trading that database becomes the bot's instinct for danger.  Patterns emerge. Rules get written. The best rules graduate into Gate 1 as permanent hardcoded checks. The bot gets smarter with every single exogenous event we document — not just from wins, but especially from losses. |

## **5.1 Loss Categories**

|  |  |  |  |
| --- | --- | --- | --- |
| **LABEL** | **CATEGORY** | **DEFINITION** | **BOT RESPONSE** |
| **A** | **Strategy Failure** | Our signal was wrong — technical or sentiment read failed | Tune signals. Adjust entry criteria. Review Gate 3 threshold. |
| **B** | **Exogenous Shock** | Outside event hijacked a valid setup — macro, geopolitical, short seller, sector contagion | Log in threat memory. Run post-loss Claude review. Candidate for new Gate 1 rule. |
| **C** | **Execution Issue** | Signal was right but timing, slippage, or overnight gap caused the loss | Review Gate 1 pre-market gap check. Adjust entry timing. |
| **D** | **Contradiction Missed** | Gate 4 should have flagged this but did not | Review Gate 4 prompt. Add the missed contradiction type explicitly. |

What rule would have prevented this?  Once a month the best suggested rules get added to Gate 1 as permanent hardcoded checks. This is how the system continuously improves. |
