|  |  |  |
| --- | --- | --- |
| **GATE 3 RESULT** | **ACTION** | **WHAT HAPPENS NEXT** |
| BEARISH — any confidence | **BLOCK** | Trade rejected. Pipeline stops. |

| BULLISH — LOW source reliability | **CAUTION** | Proceeds but size reduced. Flag logged. |
| BULLISH — MEDIUM or HIGH sources | **PASS** | Full position size. Proceeds to Gate 4. |

# **Step 6 — Install gate5\_signal.py**

| **STEP 6 gate5\_signal.py** |
| **Repo location:** backend/02\_intelligence/gate5\_signal.py  **What it is:** Gate 5 — Fourth and final Claude API call. Final BUY or SKIP decision with EV calculation.  **Why it matters:** Only reached if all previous gates passed. Claude is given a summary of everything the previous gates found and produces a win probability estimate and expected value calculation. EV formula is hardcoded. Below 4% EV = SKIP regardless of Claude's instinct. |

|  |
| --- |
| **ACTION**  ADD to backend/02\_intelligence/ |

### **The EV formula**

|  |
| --- |
| **Expected Value calculation** |
| # EV = (win\_probability × reward\_ratio) − (1 − win\_probability)  # Example with 2:1 reward:risk ratio:  # Win probability: 0.62 (62%)  # Reward ratio: 2.0 (2:1 R:R)  # EV = (0.62 × 2.0) − (1 − 0.62)  # = 1.24 − 0.38  # = 0.86 → positive edge, BUY  # Minimum threshold: EV must exceed 0.04 (4%) to generate BUY signal  # If Claude says BUY but EV < 0.04, the code overrides to SKIP |

### **How the learning loop works**

|  |  |  |
| --- | --- | --- |
| **STAGE** | **TRIGGER** | **WHAT HAPPENS** |
| **1** | Trade hits stop loss and is categorised B or D | log\_exogenous\_shock() is called with full gate context. |
| **2** | run\_post\_loss\_review() triggers automatically | Claude reviews all gate data and suggests a specific rule: IF [condition] THEN [action]. |
| **3** | Monthly review — get\_graduation\_candidates() | Surfaces rules that have appeared 2+ times with HIGH/MEDIUM confidence — ready for Gate 1. |
| **4** | Rule added to gate1\_threat\_screen.py manually | mark\_rule\_graduated() marks events as complete. Gate 1 gets smarter permanently. |
