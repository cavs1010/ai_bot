# **1. The 6-Stage Selection Funnel**

Every night at 11pm AEST the bot runs all 500 S&P 500 stocks through six progressive filters. Each stage eliminates more stocks until only the 3 highest conviction opportunities remain. Here is the complete funnel at a glance.

|  |
| --- |
| **IN PLAIN ENGLISH FIRST** |

|  |
| --- |
| Think of the bot like a head coach picking players for a team.  Stage 1 — Basic fitness test. Anyone who cannot run fast enough, is too small, or is injured gets cut immediately. That eliminates most of the 500.  Stage 2 — Performance stats. Who has been performing best recently? The bot looks at momentum — is this stock trending upward strongly right now?  Stage 3 — Character check. What is the news saying about this stock? Good news means it likely keeps going. Bad news means avoid it today.  Stage 4 — Background check. What do the official filings say? Are the executives buying or selling their own stock? Any red flags hidden in the paperwork?  Stage 5 — Final ranking. All scores combined. Top 5 are ranked. Best 3 make the team.  Stage 6 — Last look. Are all 3 from different positions? Is the playing field safe today? If anything fails this last check — substitute in the next best player.  **Only stocks that pass ALL six stages get the bots money. Everything else is eliminated.** |

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| **STAGE** | **NAME** | **WHAT IT DOES** | **ELIMINATES** | **RESULT** |
| **1** | **Hard Filter** | Removes illiquid, cheap, downtrending stocks | Penny stocks, low volume, downtrends, earnings risk | **500 → 82** |

|  |

| **PLAIN ENGLISH: The Bouncer At The Door** |

|  |
| --- |
| Before anything else, the bot asks: is this stock even worth looking at today?  Stocks get immediately eliminated if they are too cheap (hard to profit), too thinly traded (hard to exit), trending downward (wrong direction), about to report earnings (too risky), or in the wrong industry sectors (our signals do not work there).  Think of it like a job application. Before reading the CV, you check the basic requirements. No degree? Bin. Wrong experience? Bin. This stage bins roughly 85% of the S&P 500 in seconds. |

## **2.1 Hard Filter Rules**

|  |  |  |
| --- | --- | --- |
| **FILTER** | **RULE** | **WHY THIS RULE EXISTS** |
| **Liquidity** | Volume > 1,000,000 shares/day | Low volume = hard to exit. If you need to sell fast and nobody is buying you are trapped in a falling position. |
| **Market Cap** | Market cap > $2 billion | Smaller companies move on rumours and single events. Less predictable. Our signals are calibrated for established companies. |
| **Price Range** | Price between $10 and $500 | Below $10 is penny stock territory — unpredictable and manipulated. Above $500 makes position sizing awkward at our capital level. |
| **Trend Direction** | Price above SMA20. SMA20 above SMA50. | We only buy stocks already moving upward. We never try to catch falling stocks. Uptrend must be confirmed on both short and medium timeframes. |
| **Volatility Range** | ATR between 1.5% and 8% of price | Too low: stock won't move enough to hit our 2-5% target. Too high: normal daily swings trigger our stop loss. Sweet spot is 2-5% ATR. |
| **Earnings Blackout** | No earnings within 48 hours | Earnings create binary events. Stock can gap 15% either way overnight and our stop loss cannot protect against a gap. Non-negotiable exclusion. |
| **Sector Exclusion** | Exclude Utilities and REITs | These sectors move on interest rates not momentum. Our technical signals do not apply. All other sectors are eligible. |

# **3. Stage 2 — Momentum Scoring (82 → 20)**

|  |
| --- |
| **PLAIN ENGLISH: Finding The Stocks On A Hot Streak** |

|  |
| --- |
| Think of momentum like a footballer in form. You want the player who has scored in the last 5 games — not the one who had a great season 3 years ago.  The bot measures whether each stock is currently gaining strength, whether the short-term trend is above the medium-term trend, and whether real money is flowing in through volume. A stock scores highly when all three signals agree: it is trending up, the trend is strengthening, and volume confirms real buying interest.  Stocks with weak or mixed signals are eliminated here. Only the 20 with the strongest current momentum move forward. |

## **3.1 RSI — Relative Strength Index**

RSI measures whether a stock is gaining or losing strength on a scale of 0 to 100. Our target zone is 60 to 75 — strong enough to indicate real momentum but not so high that a pullback is imminent.

|  |  |  |  |
| --- | --- | --- | --- |
| **RSI RANGE** | **MEANING** | **PLAIN ENGLISH** | **SCORE AWARDED** |
| **Below 30** | Oversold | Stock has been hammered — avoid | 0 — excluded entirely |
| **30 - 50** | Weak/Neutral | No real momentum — not our target | 0 — excluded |
| **50 - 60** | Mild momentum | Starting to move — too early | +10 points — borderline |
| **60 - 70** | Strong momentum | Moving well — this is our zone | +30 points — ideal |
| **70 - 75** | Very strong | Running hot — still good but watch | +20 points — use tighter stop |
| **Above 75** | Overbought | Likely to pull back — avoid | 0 — excluded |

## **3.2 Moving Averages — The Trend Confirmation**

Moving averages smooth out daily noise to show the true direction of a stock. When shorter averages are above longer averages the stock is in a healthy uptrend.

|  |  |  |
| --- | --- | --- |
| **SIGNAL** | **POINTS** | **PLAIN ENGLISH** |
| Price above SMA20 (20-day average) | **+15** | Stock is above its recent average — short-term uptrend confirmed |
| SMA20 above SMA50 (50-day average) | **+15** | Short-term trend is above medium-term trend — uptrend is established |
| Price 3%+ above SMA50 | **+10** | Meaningful separation from medium average — strong conviction |
| SMA50 above SMA200 | **+10** | Medium trend above long trend — full bull market alignment |
| **Golden Cross in last 5 days** | **+15 BONUS** | SMA20 just crossed above SMA50 — powerful trend change signal. Fresh momentum beginning. |

The Golden Cross is one of the most reliable signals in technical analysis. When the short-term average crosses above the medium-term average it signals a shift from weakness to strength. The bot treats a fresh Golden Cross as a high priority trigger.

## **3.3 Volume Score — Confirming Real Money**

Volume tells us whether the price move is backed by real buying or just noise. A stock rising on low volume is unreliable. A stock rising on 2x its normal volume means institutions and serious money is involved.

|  |  |  |  |
| --- | --- | --- | --- |
| **VOLUME RATIO** | **MEANING** | **PLAIN ENGLISH** | **SCORE** |
| Below 1.0x average | Below normal | Less buying than usual — weak signal | **+0 points** |
| 1.0x - 1.2x average | Slightly above | Mild interest — acceptable | **+10 points** |
| 1.2x - 1.5x average | Meaningfully above | Real buying interest — good signal | **+20 points** |
| 1.5x - 2.0x average | Strong conviction | Serious money buying — strong signal | **+30 points** |
| Above 2.0x average | Exceptional | Institutions buying — very strong | **+35 points** |

# **5. Stage 4 — EDGAR & Fundamental Check (10 → 5)**

|  |
| --- |
| **PLAIN ENGLISH: Checking The Official Paperwork** |

|  |
| --- |
| News headlines can be misleading. But SEC filings cannot lie — they are legal documents. This stage digs into the official paperwork every public company must file with the US Securities and Exchange Commission.  The most powerful signal here is insider transactions. When company executives buy their own stock with their own money — they are betting on themselves. When multiple executives sell simultaneously — that is a warning. The SEC requires them to report these trades within 48 hours on Form 4.  This stage also checks the financial health of the company to ensure we are not buying into a fundamentally broken business that happens to have good momentum today. |

## **5.1 Form 8-K — Material Event Filings**

Companies must file an 8-K within 4 business days of any material event. The bot checks for 8-K filings in the last 10 days.

|  |  |
| --- | --- |
| **GOOD 8-K SIGNALS** | **BAD 8-K SIGNALS — ELIMINATE** |
| New credit facility signed | Default on debt obligation |
| Material contract announced | Departure of key executives (unexpected) |
| Acquisition completed | Bankruptcy or receivership filed |
| Earnings results filed (beat) | Material asset impairment |
| FDA or regulatory approval | Unregistered securities sale |

## **5.2 Form 4 — Insider Transactions (Most Powerful Signal)**

|  |  |  |
| --- | --- | --- |
| **INSIDER ACTIVITY** | **SCORE** | **PLAIN ENGLISH** |
| **Multiple insiders buying same week** | **+8** | When 3+ executives all buy their own stock in the same week — that is extraordinary conviction. They all believe it is going up. |
| **CEO buying large position** | **+6** | The CEO knows everything happening inside the company. A large personal purchase is the strongest inside signal possible. |
| **Single insider buying** | **+3** | Positive but less powerful than cluster buying. One person could have many reasons. |
| **Cluster selling — multiple insiders** | **-6** | Multiple executives selling simultaneously is a red flag. They may know something the market does not yet. |
| **CEO selling 20%+ of their holding** | **-5** | A CEO selling a large portion of their stake suggests declining confidence in the companys near-term prospects. |

Important nuance: A single executive selling stock is not always negative. They sell for many reasons — tax planning, buying a house, diversifying. But when multiple insiders sell simultaneously without a scheduled plan — that is the warning signal the bot acts on.

# **6. Stages 5 & 6 — Composite Scoring & Final Risk Check**

## **6.1 The Composite Score Formula**

All signals from Stages 2, 3 and 4 are combined into one final score out of 100. Stocks below 65 are eliminated. The top 3 are selected.

|  |  |  |
| --- | --- | --- |
| **COMPONENT** | **WEIGHT** | **WHY THIS WEIGHT** |
| **Momentum Score** | **35%** | This is a momentum trading system. The trend signal is our primary edge. It must be the dominant factor in selection. |
| **Sentiment Score** | **30%** | News drives short-term price more than almost anything else. Explains the WHY behind the momentum. Cannot trade momentum without knowing the story. |
| **Volume Score** | **20%** | Confirms the momentum is real and not just noise. High volume means real money. Without volume the momentum signal is unreliable. |
| **EDGAR / Fundamentals** | **15%** | Risk management layer. We are swing trading not value investing. Fundamentals do not drive short-term price but prevent us buying fundamentally broken companies. |

## **6.2 Stage 6 — The Pre-Trade Safety Checklist**

|  |  |  |
| --- | --- | --- |
| **CHECK** | **RULE** | **PLAIN ENGLISH** |
| **Sector Diversity** | All 3 stocks must be from different sectors | If all 3 are tech stocks and bad tech news hits — all 3 fall together. Different sectors protect against this. |
| **VIX Fear Index** | VIX below 20 to trade. Above 25 sit in cash. | VIX measures market fear. In high fear environments all stocks fall together regardless of quality. Cash is safer. |
| **Earnings Buffer** | Expand to 72 hour earnings exclusion | Final confirmation no surprise earnings in the next 3 days that could gap the stock overnight. |
| **Gap Check** | No stock that already gapped up 4%+ yesterday | If a stock already made its big move yesterday the momentum is likely exhausted. We buy before the move — not after. |
| **Sector ETF Alignment** | Stock's sector ETF must be above its SMA20 | A rising tide lifts all boats. A falling sector drags even great stocks down. Sector must be trending up with our stock. |

from tradingview\_screener import Scanner

import pandas as pd

from earnings\_calendar import get\_upcoming\_earnings

EXCLUDED\_SECTORS = ["Utilities", "Real Estate"]

EARNINGS\_BLACKOUT\_HOURS = 48

def stage1\_hard\_filter():

"""Stage 1: Hard filter. 500 -> ~82 stocks."""

earnings\_soon = get\_upcoming\_earnings(hours=EARNINGS\_BLACKOUT\_HOURS)

query = (

Scanner.query("america")

.select("name","close","volume","RSI","SMA20","SMA50","ATR",

"market\_cap\_basic","sector","exchange")

.where(

Scanner.col("index").isin(["S&P 500"]),

Scanner.col("volume") > 1\_000\_000,

Scanner.col("market\_cap\_basic") > 2\_000\_000\_000,

Scanner.col("close").between(10, 500),

Scanner.col("RSI").between(50, 80),

Scanner.col("close") > Scanner.col("SMA20"),

Scanner.col("SMA20") > Scanner.col("SMA50"),

)

.order\_by("volume", ascending=False)

.limit(150)

)

count, df = query.get\_scanner\_data()

# ATR filter — between 1.5% and 8% of price

df["atr\_pct"] = df["ATR"] / df["close"] \* 100

df = df[df["atr\_pct"].between(1.5, 8.0)]

# Earnings blackout filter

df = df[~df["name"].isin(earnings\_soon)]

# Sector exclusion

if "sector" in df.columns:

df = df[~df["sector"].isin(EXCLUDED\_SECTORS)]

print(f"Stage 1: {len(df)} stocks passed hard filter")

return df

### **stage2\_momentum\_scorer.py**

import pandas as pd

from tradingview\_screener import Scanner

def score\_rsi(rsi):

"""RSI score. Target zone 60-75."""

if 60 <= rsi <= 65: return 20

if 65 < rsi <= 70: return 30 # Ideal zone

if 70 < rsi <= 75: return 20 # Strong but hot

if 50 <= rsi < 60: return 10 # Mild — borderline

return 0

def score\_moving\_averages(row):

"""Moving average alignment score."""

score = 0

if row["close"] > row["SMA20"]: score += 15

if row["SMA20"] > row["SMA50"]: score += 15

if row["close"] > row["SMA50"] \* 1.03: score += 10

if row.get("SMA50", 0) > row.get("SMA200",0): score += 10

# Golden Cross bonus — SMA20 recently crossed SMA50

if row.get("golden\_cross\_days\_ago", 99) <= 5: score += 15

return score

def score\_volume(row):

"""Volume ratio score."""

avg\_vol = row.get("avg\_volume", row["volume"])

vol\_ratio = row["volume"] / avg\_vol if avg\_vol > 0 else 1

if vol\_ratio >= 2.0: return 35

if vol\_ratio >= 1.5: return 30

if vol\_ratio >= 1.2: return 20

if vol\_ratio >= 1.0: return 10

return 0

def score\_atr(row):

"""ATR range score."""

atr\_pct = row["ATR"] / row["close"] \* 100

if 2.5 <= atr\_pct <= 4.0: return 20 # Ideal

if 1.5 <= atr\_pct < 2.5: return 10

if 4.0 < atr\_pct <= 6.0: return 15

if 6.0 < atr\_pct <= 8.0: return 5

return 0

def stage2\_momentum\_score(df):

"""Stage 2: Score all stocks. Return top 20."""

scores = []

for \_, row in df.iterrows():

rsi\_s = score\_rsi(row["RSI"])

ma\_s = score\_moving\_averages(row)

vol\_s = score\_volume(row)

atr\_s = score\_atr(row)

total = rsi\_s + ma\_s + vol\_s + atr\_s

normal = min(round(total / 1.3, 1), 100) # Normalise to 100

scores.append({

"ticker": row["name"],

"price": row["close"],

"rsi": row["RSI"],

"volume": row["volume"],

"atr\_pct": row["ATR"]/row["close"]\*100,

"momentum\_score": normal

})

result = pd.DataFrame(scores)

result = result[result["momentum\_score"] >= 50]

result = result.sort\_values("momentum\_score", ascending=False).head(20)

print(f"Stage 2: {len(result)} stocks after momentum scoring")

return result

import anthropic, json

from alpaca\_news import get\_stock\_news

client = anthropic.Anthropic()

ELIMINATION\_KEYWORDS = [

"earnings miss", "guidance cut", "SEC investigation",

"class action", "CEO resignation", "CFO resigned",

"data breach", "bankruptcy", "going concern"

def check\_elimination\_keywords(headlines):

"""Instant eliminate on critical negative keywords."""

text = " ".join(headlines).lower()

for kw in ELIMINATION\_KEYWORDS:

if kw in text:

return True, kw

return False, None

def score\_sentiment\_claude(ticker, headlines):

"""Use Claude to score news sentiment -10 to +10."""

if not headlines:

return 0, "No news — neutral"

# Fast elimination check before expensive API call

eliminated, reason = check\_elimination\_keywords(headlines)

if eliminated:

return -10, f"ELIMINATED: {reason}"

prompt = f"""

Analyse ALL news for {ticker} from the last 48 hours.

Score overall sentiment from -10 to +10:

-10 = catastrophic (fraud, bankruptcy, major lawsuit)

-5 = significantly negative (earnings miss, guidance cut)

-2 = mildly negative (minor headwinds)

0 = neutral (no significant news)

+2 = mildly positive (minor positive mention)

+5 = significantly positive (beat estimates, contract win)

+8 = very positive (major partnership, acquisition target)

+10 = exceptional (transformative announcement)

Return ONLY JSON:

{{"score": X, "primary\_reason": "brief", "key\_headline": "headline",

"risk\_flags": ["flag1"], "news\_age\_hours": 24}}

Headlines: {headlines[:10]}

"""

response = client.messages.create(

model="claude-sonnet-4-20250514", max\_tokens=300,

messages=[{"role": "user", "content": prompt}]

)

result = json.loads(response.content[0].text)

return result["score"], result["primary\_reason"]

### **stage5\_composite\_scorer.py**

def calculate\_composite(row):

"""

Composite score = weighted combination of all signals.

Momentum: 35%

Sentiment: 30%

Volume: 20%

EDGAR: 15%

"""

# Sentiment normalised from -10/+10 to 0-100

sentiment\_normalised = (row["sentiment\_score"] + 10) / 20 \* 100

# Volume normalised based on ratio

avg\_vol = row.get("avg\_volume", row["volume"])

vol\_ratio = row["volume"] / avg\_vol if avg\_vol > 0 else 1

volume\_normalised = min(vol\_ratio \* 40, 100)

composite = (

row["momentum\_score"] \* 0.35 +

sentiment\_normalised \* 0.30 +

volume\_normalised \* 0.20 +

row["edgar\_score"] \* 0.15

)

return round(composite, 1)

def stage5\_composite\_rank(edgar\_df):

"""Stage 5: Calculate composite. Return top 3+ for Stage 6."""

import yfinance as yf

SECTOR\_ETFS = {

"Technology": "XLK",

"Healthcare": "XLV",

"Consumer Discretionary":"XLY",

"Industrials": "XLI",

"Financials": "XLF",

"Energy": "XLE",

"Communication Services":"XLC",

def get\_vix():

vix = yf.Ticker("^VIX")

return vix.fast\_info["last\_price"]

def get\_sector(ticker):

info = yf.Ticker(ticker).info

return info.get("sector", "Unknown")

def check\_gap(ticker):

"""Check if stock gapped up 4%+ yesterday."""

hist = yf.Ticker(ticker).history(period="3d")

if len(hist) < 2: return False

prev\_close = hist["Close"].iloc[-2]

open\_price = hist["Open"].iloc[-1]

gap\_pct = (open\_price - prev\_close) / prev\_close \* 100

return gap\_pct > 4.0

def check\_sector\_etf(sector):

"""Check sector ETF is above its 20-day SMA."""

etf = SECTOR\_ETFS.get(sector)

if not etf: return True # Unknown sector — allow through

hist = yf.Ticker(etf).history(period="30d")

sma20 = hist["Close"].rolling(20).mean().iloc[-1]

price = hist["Close"].iloc[-1]

return price > sma20

def stage6\_risk\_check(composite\_df, pot\_size):

"""Stage 6: Final safety checks. Returns 3 confirmed trades."""

# VIX check — overall market fear

vix = get\_vix()

if vix > 25:

print(f"VIX {vix:.1f} — extreme fear. NO TRADES tonight.")

return [], pot\_size

size\_multiplier = 1.0

if vix > 20: size\_multiplier = 0.6; print(f"VIX {vix:.1f} — reducing size 40%")

elif vix > 15: size\_multiplier = 0.8; print(f"VIX {vix:.1f} — reducing size 20%")

selected = []

used\_sectors = set()

reserve\_pool = composite\_df.to\_dict("records")

for stock in reserve\_pool:

if len(selected) >= 3: break

ticker = stock["ticker"]

sector = get\_sector(ticker)

# Sector diversity check

if sector in used\_sectors:

print(f" SKIP {ticker}: duplicate sector {sector}")

continue

# Gap check

if check\_gap(ticker):

print(f" SKIP {ticker}: gapped up yesterday — move already made")

continue

# Sector ETF alignment

if not check\_sector\_etf(sector):

print(f" SKIP {ticker}: sector {sector} below SMA20")

continue

pos\_size = (pot\_size / 3) \* size\_multiplier

selected.append({\*\*stock, "sector": sector, "position\_size": pos\_size})

used\_sectors.add(sector)

print(f" SELECTED {ticker} [{sector}]")

if not selected:

print("No qualifying stocks tonight — sitting in cash")

return selected, pot\_size
