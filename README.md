# 🤖 ai_bot

Autonomous stock trading bot — scans US markets overnight, scores momentum candidates, and (eventually) places trades via Alpaca. Built in Python with companion Jupyter notebooks for every module.

📌 Spec & roadmap → [`spec/master.md`](spec/master.md) · [`spec/iteration-01-roadmap.md`](spec/iteration-01-roadmap.md)

## 📋 Prerequisites

| Requirement | Notes |
|-------------|-------|
| 🐍 **Python 3.11+** | Project uses 3.12 in `venv/` |
| 💻 **Cursor** (or any IDE) | Recommended for AI-assisted development |
| 🏦 **Alpaca** paper account | [alpaca.markets](https://alpaca.markets) — free paper trading keys |
| 🧠 **Anthropic** API key | [console.anthropic.com](https://console.anthropic.com) — for sentiment (Phase 4+) |
| 📰 **NewsAPI** key | [newsapi.org](https://newsapi.org) — free tier (100 req/day) |
| 📅 **Finnhub** key | [finnhub.io](https://finnhub.io) — free tier, earnings calendar |

> 🔓 **No key needed:** Yahoo Finance price data (`yfinance`) and TradingView screener work without API keys.

## 🚀 Quick Start (Install)

Run everything from the **project root** (`ai_bot/`).

### 📦 How dependencies work

| File / folder | Role |
|---------------|------|
| [`requirements.txt`](requirements.txt) | **Committed to git** — lists every library the project needs |
| `venv/` | **Local only** (gitignored) — your isolated Python environment where those libraries get installed |

You create `venv/` once on your machine, then install everything from `requirements.txt`. You never pip-install packages one by one.

### 1️⃣ Clone & enter the repo

```bash
git clone <your-repo-url> ai_bot
cd ai_bot
```

### 2️⃣ Create & activate a virtual environment

```bash
python3 -m venv venv
source venv/bin/activate        # macOS / Linux
# venv\Scripts\activate         # Windows
```

✅ You should see `(venv)` in your terminal prompt.

### 3️⃣ Install all dependencies (one command)

```bash
pip install -r requirements.txt
```

That's it — all project dependencies are installed.

### 4️⃣ Configure environment variables

```bash
cp .env.example .env
```

Edit `.env` and uncomment/fill in the keys you have:

| Variable | Required for | Module |
|----------|--------------|--------|
| `ALPACA_API_KEY` | Dynamic price ceiling | `universe_filter.py` |
| `ALPACA_SECRET_KEY` | Dynamic price ceiling | `universe_filter.py` |
| `ALPACA_BASE_URL` | Paper vs live broker | `universe_filter.py` |
| `NEWS_API_KEY` | News headlines | `data_fetcher.py` |
| `FINNHUB_API_KEY` | Earnings filter | `universe_filter.py` |
| `ANTHROPIC_API_KEY` | Sentiment analysis | Phase 4+ (not built yet) |

> ⚠️ **Never commit `.env`** — it is gitignored. Only `.env.example` is tracked.

### 5️⃣ Create data folders (if missing)

```bash
mkdir -p data logs
```

## 🧪 How to Test (Terminal)

Every module has a built-in smoke test. **Always run from the project root** so paths like `data/watchlist.csv` resolve correctly.

```bash
source venv/bin/activate
cd /path/to/ai_bot    # project root
```

### 📊 Phase 2 — Data layer

```bash
python backend/00_data/data_fetcher.py
```

**✅ Expected:** ~60 rows of AAPL price data + at least 1 news headline (needs `NEWS_API_KEY`).

### 🔍 Phase 3 — Tier 1 universe filter (weekly)

```bash
python backend/01_scanner/universe_filter.py
```

**✅ Expected:** `[universe] complete: ~60–80 stocks saved to data/watchlist.csv`

- Works **without** Alpaca keys (uses fallback price ceiling `$360`)
- Works **without** Finnhub key (skips earnings filter with a warning)

### 📈 Phase 3 — Tier 2 momentum scanner (nightly)

```bash
# Run Tier 1 first if data/watchlist.csv doesn't exist
python backend/01_scanner/momentum_scanner.py
```

**✅ Expected:** Ranked table of top momentum candidates (score ≥ 2).

> 💡 Each module also has a `*_playground.ipynb` notebook in the same folder for interactive testing from your IDE.

## 🤖 Agent Quick Reference

Use this block when an agent needs to install, test, or verify the project:

```

SETUP=python3 -m venv venv && source venv/bin/activate && pip install -r requirements.txt
PYTHON=venv/bin/python                  # after venv is activated
ENV=copy .env.example → .env, fill API keys

TERMINAL_TESTS (in order):
  python backend/00_data/data_fetcher.py
  python backend/01_scanner/universe_filter.py
  python backend/01_scanner/momentum_scanner.py   # needs data/watchlist.csv

KEY_PATHS:
  watchlist output → data/watchlist.csv
  module tests     → python backend/<layer>/<module>.py
  spec/roadmap     → spec/iteration-01-roadmap.md
```
